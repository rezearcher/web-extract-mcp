# Web Extract MCP Server

Hosted MCP server (streamable HTTP) for web retrieval by agents.

Endpoint: `https://assetfactory-jobs-x402.sigrunner.workers.dev/mcp/web`

Free tools:
- `web_extract_preview` - capped clean-markdown extraction of a URL, with a prompt-injection screen.
- `sitemap_preview` - first 20 URLs from a site's sitemaps.
- `get_premium_access` - how to call the full paid endpoints.
